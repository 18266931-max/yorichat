# PureChat 登录 + 好友功能设计方案（简单版）

## 一、登录 / 注册

### 1.1 登录方式

只做一种：**用户名 + 密码**

- 用户名：2~20 个字符
- 密码：6~20 个字符，不要求复杂度
- 没有"忘记密码"，记不住就重新注册

### 1.2 登录页
- 全屏居中白色卡片
- 用户名输入框 + 密码输入框 + 登录按钮
- 底部："没有账号？去注册"

### 1.3 注册页
- 同样卡片布局
- 用户名 + 密码 + 确认密码 + 注册按钮
- 底部："已有账号？去登录"

### 1.4 登录状态
- 登录成功 → `localStorage` 存用户名
- 打开网页检查有没有 → 有就进主页
- 退出登录 → 清掉跳回登录页

## 二、好友系统

### 2.1 添加好友流程

```
用户输入对方用户名 → 点击搜索 → 显示搜索结果 → 点击"加好友" → 对方出现在好友列表
```

就这一条线，没有审批、没有好友请求、没有同意/拒绝。

### 2.2 页面设计

#### 添加好友入口
- 在左侧导航栏加一个「加好友」按钮（图标：UserPlus）
- 点击后中间面板变成"添加好友"界面

#### 添加好友面板
- 顶部一个搜索框："输入用户名搜索"
- 输入后点搜索或按回车
- 搜索结果展示：
  - 头像（用户名首字）+ 用户名
  - 如果已经是好友 → 显示"已是好友"，按钮灰色
  - 如果是自己 → 显示"不能加自己"
  - 如果不是好友 → 显示"添加"按钮，绿色
- 点击"添加"→ 按钮变成"已添加"，1秒后消失该条结果

#### 好友列表
- 把原来"联系人"页面改成"好友列表"
- 显示所有好友，按添加时间倒序排列
- 每个好友显示：头像 + 用户名 + 在线状态（绿点/灰点）
- 点击好友 → 直接进入聊天（已有会话就切换过去，没有就新建）
- 长按或右键 → 可以删除好友

### 2.3 数据结构

**users.json**（用户数据）：
```json
[
  { "id": 1, "username": "admin", "password": "123456", "nickname": "管理员" }
]
```

**friends.json**（好友关系）：
```json
[
  { "userId": 1, "friendId": 2 },
  { "userId": 2, "friendId": 1 }
]
```

双向存储，A 加 B 为好友 = 存两条记录。

## 三、后端 API

全部用 Express，一个文件搞定，数据存 JSON 文件。

### 3.1 登录相关

```
POST /api/register       { username, password }        → 注册
POST /api/login          { username, password }        → 登录，返回用户信息
```

### 3.2 好友相关

```
GET  /api/users/search?q=xxx                           → 搜索用户（模糊匹配用户名）
POST /api/friends/add     { friendId }                 → 添加好友
GET  /api/friends                                     → 获取我的好友列表
DELETE /api/friends/:friendId                         → 删除好友
```

### 3.3 数据文件

```
server/
  ├── index.js          ← 后端入口，一个文件
  ├── users.json        ← 用户数据
  └── friends.json      ← 好友关系
```

## 四、前端路由

```
/login    → 登录页
/register → 注册页
/         → 聊天主页（需登录）
```

主页内部用状态切换，不用路由：
- 左侧导航：消息 | 好友 | 添加好友 | 设置
- 中间面板根据导航切换：
  - 消息 → 会话列表
  - 好友 → 好友列表
  - 添加好友 → 搜索 + 添加面板
  - 设置 → 设置页

---

## 五、实现步骤

| 步骤 | 内容 |
|------|------|
| 1 | 装前端路由，写登录页 + 注册页 UI |
| 2 | 写 Express 后端（注册 + 登录） |
| 3 | 前后端联调，登录后进聊天主页 |
| 4 | 后端加好友相关 API（搜索 + 添加 + 列表 + 删除） |
| 5 | 前端加"添加好友"面板 + 好友列表页面 |
| 6 | 好友列表点击直接开聊，退出登录功能 |

## 六、技术要点

| 项目 | 方案 |
|------|------|
| 前端路由 | React Router v6 |
| 登录状态 | localStorage 存用户名 |
| 后端 | Express，一个文件 |
| 数据存储 | JSON 文件（users.json + friends.json） |
| 密码 | 明文存储 |
| 好友关系 | 双向存储，双向删除 |
| 搜索 | 简单字符串 includes 匹配 |
